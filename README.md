🚨 Travel Emergency Assist

A full-stack web application that helps travelers quickly find nearby emergency services such as hospitals, ATMs, hotels, restaurants, petrol pumps, and vehicle repair services using their current location.

🌟 Features

- 📍 Real-time geolocation
- 🚑 Emergency request handling
- 🏥 Nearby hospital search
- 🍴 Nearby restaurants
- 🏨 Nearby hotels
- ⛽ Nearby petrol pumps
- 🏧 Nearby ATMs
- 🚗 Nearby vehicle repair services
- 🗺️ Google Maps integration
- 🌙 Dark mode support
- 📱 Responsive user interface
- ☁️ Backend deployed on Render

🛠️ Tech Stack

Frontend

- HTML5
- CSS3
- JavaScript

Backend

- Node.js
- Express.js
- CORS

Deployment

- GitHub
- Render

Database (Upcoming)

- MongoDB Atlas

🚀 Installation

Clone the repository

git clone https://github.com/abhishekyadav1601/Travel-Emergency-Assist.git

Go to the project folder

cd Travel-Emergency-Assist

Install dependencies

npm install

Run the backend

node frontend/backend/B1.js

Open "frontend/index.html" in your browser.
